# E-commerce Frontend

This is a modern E-commerce frontend website built using React and Vite.

## Features

* Home Page
* Product Listing
* Product Details Page
* Cart Page
* Login & Signup Page
* Responsive Design
* React Router Navigation

## Technologies Used

* React JS
* Vite
* CSS
* React Router DOM

## Installation

Clone the repository:

```bash
git clone https://github.com/sunilkushwaha8081/E-commerce-frontend.git
```

Go to project folder:

```bash
cd E-commerce-frontend
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm run dev
```
